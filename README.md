Portfólio profissional de Gustavo Henrique Moraes Filho, Analista de Automações e IA para Atendimento.

O site apresenta meu posicionamento profissional, experiências, projetos e formas de contato, com foco em automações inteligentes para WhatsApp, CRM, tráfego pago, gestão de leads e integração de sistemas.

## Acesse o site

[https://gustavohmfilho.github.io/pagina-pessoal/](https://gustavohmfilho.github.io/pagina-pessoal/)

## Sobre o projeto

Este portfólio foi desenvolvido para destacar minhas principais frentes de atuação:

- IA de atendimento 24h para WhatsApp
- Automações com n8n
- Integrações com CRM, APIs e webhooks
- Gestão e qualificação de leads
- Fluxos para Google Ads e Facebook Ads
- Uso de Supabase, Postgres e Redis em automações escaláveis

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React
- GitHub Pages

## Como rodar localmente

```bash
npm install --legacy-peer-deps
npm run dev
```

Depois, acesse:

```text
http://localhost:3000
```

## Build estático

Para gerar a versão estática usada no GitHub Pages:

```bash
$env:GITHUB_PAGES='true'
npm run build
```

O conteúdo exportado fica na pasta `out`.
